好，这个问题**很标准，也很关键**。我按 **Ubuntu 18.04 + 饥荒服务器** 的实际使用场景，给你一套**不绕弯、可直接照做**的方案，并把“为什么要这么做”讲清楚。

---

## 一、先说结论（你该怎么开端口）

### **方案 A（推荐）**：只开放饥荒需要的端口

👉 **10888 / 10998 / 10999（UDP 为主）**

### **方案 B（不推荐但有人用）**：直接放行所有端口

👉 省事，但**不安全**

下面我一步步教你在 **Ubuntu 18.04** 里怎么做。

---

## 二、确认你现在用的是哪个防火墙（很重要）

Ubuntu 18.04 **90% 用的是 UFW**，先看一眼：

```bash
sudo ufw status
```

- 显示 `Status: active` → 用 **UFW**
    
- 显示 `inactive` → 防火墙没开（那系统层面其实已经“全放行”了）
    

下面我**只按 UFW 来讲**，这是最规范的。

---

## 三、推荐做法：只开放饥荒端口（安全 & 稳定）

> ⚠️ 饥荒联机 **主要用 UDP**，别只开 TCP

### 1️⃣ 开放 10888（UDP）

```bash
sudo ufw allow 10888/udp
```

### 2️⃣ 开放 10998（UDP）

```bash
sudo ufw allow 10998/udp
```

### 3️⃣ 开放 10999（UDP）

```bash
sudo ufw allow 10999/udp
```

### 4️⃣（可选但推荐）TCP 也顺手开

有些管理工具 / 状态查询会用 TCP：

```bash
sudo ufw allow 10888/tcp
sudo ufw allow 10998/tcp
sudo ufw allow 10999/tcp
```

### 5️⃣ 重新加载并查看规则

```bash
sudo ufw reload
sudo ufw status numbered
```

你应该能看到类似：

```
10888/udp    ALLOW
10998/udp    ALLOW
10999/udp    ALLOW
```


---

## 五、云服务器用户【非常重要的一点】

> **系统防火墙开了 ≠ 外网就能连**

如果你用的是：

- 阿里云
    
- 腾讯云
    
- AWS
    
- Vultr / Linode
    

你**还必须**在【云厂商控制台】里：

👉 **安全组 / 防火墙**

- 开放：
    
    - UDP：10888 / 10998 / 10999
        
    - TCP（可选）：同上
        
- 来源：`0.0.0.0/0`
    

否则：

> Ubuntu 里全开了，但外面还是连不上 ❌

---

## 六、快速自检（推荐你做）

### 看端口有没有在监听

```bash
sudo ss -lunp | grep -E "10888|10998|10999"
```

能看到 `udp` 在监听，说明饥荒服务器本身是正常的。

---

## 七、给你一个“老司机建议”

- ✅ **只开 10888 / 10998 / 10999（UDP）**
    
- ❌ **不要全端口放行**
    
- 🔒 SSH 建议限制 IP
    
- 🧠 饥荒后台（你前面那个 8080）也别忘了单独开
